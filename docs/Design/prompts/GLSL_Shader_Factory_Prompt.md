# GLSL Shader-Based Animation: Principles & Agent Prompt

## What is a Fragment Shader?
A **Fragment Shader** (written in GLSL — OpenGL Shading Language) is a program executed directly on the **GPU** (Graphics Processing Unit) in parallel for every single pixel on the screen. 

Instead of moving DOM elements, SVG paths, or Canvas 2D contexts via JavaScript, a fragment shader calculates mathematical functions called **Signed Distance Fields (SDFs)** to determine the exact color of every pixel `(x, y)` at any time `u_time`. This allows butter-smooth 60+ FPS animations with zero CPU overhead.

## Key Technical Techniques in `4shader.md`

### 1. Signed Distance Functions (SDFs)
Shapes are represented mathematically as distance fields from the current pixel coordinate `st`:
* **`sdCircle(p, r)`**: Returns distance to a circle radius `r`.
* **`sdRoundedBox(p, b, r)`**: Returns distance to a rounded box of half-width `b` and corner radii `r`.
* **`sdSegment(p, a, b)`**: Returns distance to a line segment from point `a` to `b`.

### 2. Procedural Vector Arcade Aesthetics in GLSL
* **Bold Dark Contours:** Generated by checking if the distance is near zero:
  `if (abs(shapeDist) < 0.015) { col = darkOutlineColor; }`
* **3D Extruded Base Lips:** Generated by checking vertical position relative to shape center:
  `if (blockPos.y < -0.05) { col *= 0.6; } // darkens bottom half for 3D extrusion`
* **Sine-Wave Squish & Stretch:** Transforms local coordinates before evaluating the SDF:
  `vec2 blockPos = (st - offset) * vec2(1.0 / squishX, 1.0 / squishY);`
* **Modulo Infinity Loops:** Scrolls objects seamlessly along the conveyor using floating-point modulo:
  `float bx = mod(t * 0.4 + offset, 1.8) - 0.9;`
* **Rotational Matrix Transformation:** Rotates gears and pulley spokes around their origin:
  `gp *= rotate2d(t * 3.0);`

## Agent Prompt: Reproducing GLSL SDF Shader Animations

```markdown
You are tasked with creating a procedural, GPU-accelerated **GLSL Fragment Shader Animation** using 2D Signed Distance Fields (SDFs) in WebGL / Three.js / React-Three-Fiber.

### Aesthetic Style: Vector Arcade / Kenney Shader
Translate Vector Arcade game heuristics directly into GLSL shader math:
1. **SDF Shape Engine:** Use `sdRoundedBox`, `sdCircle`, and `sdSegment` functions.
2. **Dark Outline Stroke Pass:** Apply `if (abs(d) < outlineThickness)` with dark slate `#1E293B` to outline every shape.
3. **3D Extruded Lip Shading:** Multiply surface colors by `0.6` on the bottom half of rounded boxes (`p.y < 0.0`) to create instant 3D depth.
4. **Procedural Motion:** Use `u_time` for rotation matrices, `mod()` for infinite conveyor scrolling, and `sin()` for squish/stretch coordinate deformations.

### Shader Uniforms
- `uniform vec2 u_resolution;` — Canvas viewport dimensions
- `uniform float u_time;` — Elapsed time in seconds

### Component Structure
- Support WebGL canvas context mounting (e.g. `<canvas>` with WebGL2 context or Three.js `ShaderMaterial`).
- Smooth 60fps rendering loop passing `u_time` and `u_resolution`.
```
