# Hero Background SVG — 10 Variant Prompts

Shared rule behind every variant: a smooth two-tone color gradient as the base, plus one accent motif scattered across 2-3 parallax depth layers, always dimmer/lower-opacity than the gradient beneath it so it never fights the foreground. Four variants nudge the motif toward classic-arcade iconography (a mystery block, an invader silhouette, a heraldic shield, a coin token) — stylized and abstracted, not literal reproductions. The rest leave the motif fully open. Every variant also gets its own distinct character of motion — no two should move the same way. Animate only via CSS `transform`/`opacity` — never toggle `display`, animate layout properties, or use SMIL motion paths.

---

## Variant 1: Electric Violet — Tumbling Block

```markdown
Design a full-bleed SVG background for a game portfolio hero section. A smooth two-stop color gradient, light lavender fading into deep royal purple, vivid and saturated, no texture or noise.

Scatter a stylized cube motif across the canvas in 2-3 depth layers (near, mid, far) — abstracted like a classic platformer's mystery block, a simple bold symbol on its face, not a literal character reproduction. Keep every layer dimmer than the gradient beneath it, in a single near-white or warm highlight tone.

Give the blocks a slow tumbling rotation as they drift, like they're gently spinning end over end in zero gravity — the nearer/larger layer tumbling a touch faster than the farther/smaller one. The gradient underneath stays still. Animate only via CSS `transform`/`opacity` — never toggle `display`, animate layout properties, or use SMIL motion paths; if anything needs a frame-swap look, crossfade it with opacity, not a display flip.
```
