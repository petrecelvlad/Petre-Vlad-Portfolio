# Hero Banner Reimagination Prompt

## Purpose
This document provides a comprehensive agent prompt to reimagine the portfolio application's **Hero Banner** into a striking, immersive **Tactile / Steampunk Artifact**. 

It combines mechanical control consoles, live interactive status dials, animated gearwork, and custom artisan plaques to immediately establish the user's creative identity upon page load.

---

## Copy-Paste Agent Prompt

```markdown
You are tasked with reimagining and rebuilding the portfolio application's **Hero Banner** using the **Tactile & Steampunk Design Aesthetic**.

### Design Concept: "The Artisan Developer's Command Chassis"
Rather than a standard flat text block with generic social links, the Hero Banner is rendered as a physical, multi-layered machine console mounted on a dark oak/slate chassis with forged blued-steel corner brackets and an elevated crimson banner plaque.

---

### Key Structural Modules to Build

#### 1. Header Banner Plaque
- **Crimson & Gold Guild Ribbon:** Suspended over the top edge of the board with 3D drop-shadows.
- **Embossed Title:** Bold display typography ("FULL-STACK ARCHITECT & TACTILE UI CREATOR") with dark stroke outlines (`paintOrder="stroke fill"`) and gold gradient fill.

#### 2. Central Artisan Console Panel
- **Parchment & Oxblood Leather Surface:** Dual-texture layout featuring a central parchment document for the bio/summary flanked by leather-backed instrument pods.
- **Dynamic Avatar/Emblem Pod:** Circular brass-framed porthole or vacuum-glass lens housing the creator's avatar or interactive 3D guild emblem, framed by interlocking animated gear rings.

#### 3. Interactive Instrument Matrix (Live Indicators)
- **Steam Pressure Gauge (System Status):** Live interactive dial indicating real-time system performance, project completion rates, or activity streaks.
- **Vacuum Tube Skill Counters:** Glowing incandescent glass tubes displaying years of experience, total commits, or key skill tiers.
- **Ticker Tape Feed:** Mechanical rolling ticker ribbon displaying current status (e.g., `"AVAILABLE FOR CONTRACTS • BUILDING TACTILE ENGINE v2.0 • FORGING NEW REPOS"`).

#### 4. Mechanical Action Levers & Switches (CTAs)
- **Knife-Switch & Lever Buttons:**
  - *"INSPECT PROJECTS"* -> Heavy brass lever button with physical click down-state and steam particle feedback.
  - *"DISPATCH MESSAGE"* -> Weighted knife-switch trigger or wax-sealed parchment CTA.
  - *"DOWNLOAD COG-RESUME"* -> Brass-trimmed scroll seal button.

#### 5. Decorative Hardware Accents
- **Blued Steel Corner Brackets:** Forged 90-degree corner caps with silver/steel rivets.
- **Pneumatic Side Pistons:** Telescoping cylinder rods along the left and right borders of the hero frame.
- **Copper Pipe Vents:** Top/bottom subtle brass pipe fittings emitting ambient steam or subtle light glow.

---

### Technical & Aesthetic Execution
- **Strict Tactile Palette:**
  - Dark Oak Frame (`#8C5828` -> `#673E19` -> `#4A2A0C`)
  - Blued Steel Brackets (`#CBD5E1` -> `#64748B` -> `#334155` -> `#1E293B`)
  - Parchment Document (`#FFF5E1` -> `#F3E3C3` -> `#E6CE9E`)
  - Oxblood Leather Accent (`#4A121A` -> `#2D0A10`)
  - Amber Filament Glow (`#F59E0B`)
- **Responsive & Accessible:** Fluidly scales across mobile, tablet, and ultra-wide desktops without breaking aspect ratios or obscuring key CTAs.
- **Smooth Animations:** Framer Motion or Motion/React for gear rotation, needle pressure physics, and lever toggle states.
```
