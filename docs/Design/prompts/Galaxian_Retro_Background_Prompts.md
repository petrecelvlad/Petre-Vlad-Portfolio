# Galaxian-Style Retro Background — 5 Variant Prompts

## Variant 1: Twilight Violet Squadron

```markdown
Design a full-bleed SVG background for a game portfolio hero section, NES/SNES pixel-art style — blocky sprites built from crisp square pixels, no anti-aliasing, a tight retro palette. A smooth two-stop gradient base, soft twilight violet fading into deep purple.

Build a back "command" tier of Galaxian flagship sprites and a front "drone" tier of regular Galaxian enemy sprites — draw the actual sprites from the game (Namco, 1979), just recolored into this palette. Don't invent or reinterpret the shape. Keep every sprite dimmer/lower-contrast than the gradient beneath it, in a single near-white or bright lilac highlight tone.

The back tier sways gently in place. The front tier marches in a loose formation, and every so often one drone peels off, dives down in a curved arc, and loops back up to rejoin formation elsewhere. Animate only via CSS `transform`/`opacity` — never toggle `display`, animate layout properties, or use SMIL motion paths; any sprite-frame flap must crossfade with opacity. The gradient underneath stays still.
```
